**Project Overview**

This portfolio project develops an Enterprise Digital Transformation Framework for Mid-Sized Organisations and translates the framework into a Power BI business intelligence solution.

The project demonstrates how business analysis, digital transformation concepts, and data visualisation can be combined to support organisational decision-making.
